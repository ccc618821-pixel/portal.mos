Приложение выводит каталог моделей обуви из PostgreSQL: изображение, категория, наименование,
производство, состав, цена со скидкой и суммарное количество пар. Скидка 25 % действует на модели,
на которые не было заказов в предыдущем календарном месяце (относительно даты расчёта).
Модели с суммарным остатком не более 3 пар подсвечены светло-красным.

## Подготовка

1. Установите Python 3.9+ (вместе с Tkinter — входит в стандартный установщик Windows) и PostgreSQL.
2. Создайте пустую базу данных (в pgAdmin: Databases → Create → Database, имя `boots`).
3. Откройте в ней Query Tool и выполните скрипт `sql/boots.sql` — он создаёт таблицы и загружает данные.
4. Установите зависимость: `pip install -r requirements.txt`.
5. Параметры подключения заданы в `config.py`: `db_host`, `db_port`, `db_name`, `db_user`, `db_pass`
   (по умолчанию `localhost`, база `boots`, пользователь `postgres`, пароль `Timon2008`, порт `5432`.).
   Если у вас другие значения — измените их там.
6. Запуск: `python main.py`.

Чтобы проверить расчёт скидки на другую дату, задайте переменную окружения
`CHUDO_CALCULATION_DATE=ГГГГ-ММ-ДД` (например, `2026-05-20` — скидки не будет у моделей, заказанных в апреле).
